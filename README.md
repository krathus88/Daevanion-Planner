# Daevanion Planner

Plan and optimize your **AION 2** Daevanion boards: pick nodes, set ability priorities, and find the cheapest routes across your boards.

**Live site:** https://krathus88.github.io/Daevanion-Planner/

## Getting started

```bash
npm install
```

```bash
npm run dev
```

See `package.json` for the other scripts.
